SLIDE 3: Why CampusVault is Agentic RAG (⏱️ Time: 1:00 - 1:40)
===================================================================
[Tip: 3 main pillars explain karein]

Is problem ko solve karne ke liye CampusVault basic RAG nahi, balkay true Agentic RAG use karta hai teen main pillars ke sath:

1. Agentic Query Router: Hamara router student ki query ko inspect karke 6 core engineering subjects aur 16-week semester syllabus mein map karta hai, aur best retrieval strategy decide karta hai.

2. Strict Confidence Gate: Humne 0.65 cosine similarity barrier lagaya hai. Agar peer notes mein context na ho, toh system jhoota answer banane ki bajaye saaf disclaimer deta hai: "Operating in General AI Mode."

3. AST-Aware Chunking: Hum character slicing ki bajaye Abstract Syntax Tree use karte hain, taake Python/C++ code functions aur LaTeX math derivations beech mein se cut na hon.

SLIDE 4: Grounding & Math Engine (⏱️ Time: 1:40 - 2:15)
===================================================================
[Tip: Citations aur KaTeX math highlights show karein]

Academic accuracy ke liye, CampusVault ke har response ke sath Peer-Grounded Citations aati hain jahan student exact senior note aur confidence percentage dekh sakta hai.

Saath hi, matrices, binary math aur networking equations ke liye humne client-side KaTeX rendering di hai. 

Groq Llama 3.3 70B aur Server-Sent Events ke zariye answer sub-500 millisecond time-to-first-token ke sath live stream hota hai.

SLIDE 5: Full-Stack Technology Matrix (⏱️ Time: 2:15 - 2:45)
===================================================================
[Tip: Tech stack table par mouse hover karein]

Hamara full-stack architecture production ready hai:

• Frontend: React, TypeScript, aur Tailwind CSS — jo mobile aur desktop dono par smooth chalta hai.
• Backend: FastAPI async orchestrator.
• Inference: Groq Llama 3.3 70B ultra-fast reasoning.
• Embeddings: FastEmbed ONNX runtime — jo server par locally chalta hai, yani zero GPU cost aur zero external API dependency.
• Vector DB: PostgreSQL pgvector — jo under 20 milliseconds mein hybrid search deliver karta hai.

SLIDE 6: End-to-End Query Workflow (⏱️ Time: 2:45 - 3:20)
===================================================================
[Tip: Step 1 se 4 tak flow explain karein]

Hamara 4-step query workflow bohot simple hai:

• Step 1: Student query bhejta hai; FastAPI Router subject, week aur intent classify karta hai.
• Step 2: FastEmbed locally 384-dim vector bana kar pgvector se sub-20ms mein search karta hai.
• Step 3: Confidence Gate check karta hai ke score 0.65 se ooper hai ya nahi.
• Step 4: Groq Llama 3.3 70B verified citations aur KaTeX math ke sath token-by-token answer stream kar deta hai.
